# Editorial Desk-Screen Action

**When to use:** after a near-complete draft when the user wants a high-impact-journal editor perspective on clinical validity, scope fit, novelty, analysis adequacy, and what additional evidence would be needed.

Follow `docs/critical_review_protocol.md` §5 and use `scripts/critical_prompts/editor.txt`.

Target: **[user-specified file(s), or full manuscript]**

1. Identify the paper's actual clinical/scientific field and intended contribution.
2. If current literature benchmarking is needed, use PubMed/web/available evidence tools and ground factual benchmark claims.
3. Run a higher-reasoning ChatGPT desk-screen. Add an independent Shellby reviewer pass when useful. Optional OpenRouter review can be added if available.
4. Synthesize: clinical validity, novelty/scope, methods/analysis adequacy, missing validation, and a desk-screen style disposition.
5. Save the report under `review/critical/`.

This is advisory editorial judgment. It does not replace grounded citation/number verification or the user's own journal decision.
